# Security

Please report suspected security issues privately to nishaadbharaswadkar@gmail.com.

Include the affected version, a minimal reproduction, and the expected impact. Do not send passwords, login cookies, authentication codes, or private social messages. Use test accounts or public pages when possible.

Quietlane's restrictions apply only inside its own browser. It is a self-control tool, not a tamper-proof parental-control or device security boundary. Third-party websites and operating-system browsers have their own security/data practices.

Native builds and live platform behavior must be verified separately from the JavaScript test suite.
